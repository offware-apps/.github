# Offware

Software that works switched off.

Apps for daily life that do their whole job on your device: no signal, no
server, no account. Open source, private by default, your data in a file you
own. The promise in full is in [Vision](https://github.com/offware-apps/Vision).

| App | What it does | Try it |
| --- | --- | --- |
| [MAX Finder](https://github.com/offware-apps/MAX-Finder) | Every SNCF train where a free MAX seat is reservable | [offware-apps.github.io/MAX-Finder](https://offware-apps.github.io/MAX-Finder/) |
| [Postcards](https://github.com/offware-apps/Postcards) | Every place you have been, privately, offline | [offware-apps.github.io/Postcards](https://offware-apps.github.io/Postcards/) |
| [CVSS Lens](https://github.com/offware-apps/cvss-lens) | A CVSS 3.1 vector in plain words, scored in one file | [offware-apps.github.io/cvss-lens](https://offware-apps.github.io/cvss-lens/) |
